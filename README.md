# Sistema de gestión de una tienda.

Este es un sistema de consola desarrollado en "PYTHON" para administrar el inventario de una tienda: registra productos, los coloca en una lista, los busca, los elimina y calcula datos importantes del inventario.

# Descripcion del sistema.
Al iniciar el programa pide "USUARIO Y CONTRASEÑA" y valida el acceso antes de mostrar el menú. Si el acceso es correcto, el menú se repite hasta que el usuario elige la opción "SALIR". El programa cuenta con 3 intentos para colocar los datos correctos de usuario y contraseña, si quien usa el programa pierde los 3 intentos este se cierra.

Cada producto tiene cuatro datos: "código, nombre, precio y cantidad". Los datos se guardan en listas mientras el programa este abierto, al cerrarlo estos  datos se perderan.

# Estado del proyecto

-Login con usuario y contraseña (3 intentos para ingresar datos correctos, si esto no se cumple el programa finaliza su funcion)
- Menú de opciones
- Agregar producto con validaciones
- Listar productos
- Buscar producto
- Eliminar producto
- Calculos del inventario

# CONCLUSION
El programa permite administrar el inventario de una tienda desde la consola: agregar, listar, buscar y eliminar productos, además de calcular el valor total, el promedio de precios y los productos más caros y más baratos.
Además, el acceso con usuario y contraseña protege la información, y las validaciones evitan errores al ingresar los datos. 
Es una herramienta sencilla y útil para que un negocio pequeño organice sus productos y tome las mejores decisiones.
